# 🎮 XO Game

A simple console-based **XO (Tic-Tac-Toe) game** built using **Python**.

## ✨ Features

- 👥 Two-player gameplay
- 🎯 3×3 game board
- 🏆 Automatic winner detection
- 🔄 Turn-based gameplay

## 🛠️ Technologies Used

- Python

## 📚 Concepts Used

- Variables
- Lists
- Functions
- Loops
- Conditional statements
- User input
- Game logic
